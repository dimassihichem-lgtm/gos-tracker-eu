Two ways to add: individually via "+ Add client", or bulk via CSV import
Bulk import clients
  1. Download the Excel template shared by the GOS team (filename: GOS_2026_Import_Template.xlsx)
  2. Fill in your clients, one per row. Dropdowns are provided for Type, Country, Outreach By, and Status.
  3. In Excel: File → Save As → CSV (Comma delimited)
  4. Open the CSV in Notepad, select all (Ctrl+A), copy (Ctrl+C)
  5. Paste it in the box below (Ctrl+V), then click Import
